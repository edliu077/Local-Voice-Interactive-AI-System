# 本地语音交互AI系统（Local Voice-Interactive AI System）— Privacy and candidate boundary

An explicit source whitelist excludes runtime, cache, recorded speech, full transcripts, quality Trace, owner, actual configuration, secrets, reference voice/embedding, Avatar images/frames/coordinates and build products. Ordinary business WAVs/logs may reach disk in the original system. CYBER_QUALITY_TRACE/CYBER_STT_EVIDENCE remain default-off and are not enabled here.

All upstream sample web/CDN consumers and vendor source are absent. Future external dependencies still need network/privacy review. Loopback is not public-hosting authentication. One hardware-identifying UUID in a mock NVML fixture was replaced in this candidate only by a clearly synthetic UUID; production identity/resource logic is unchanged. Protected-root constants are refusal checks, not live user configuration.

The original seven Git ancestors are retained. A bounded scan checks their reachable unique blobs and current files for credential-shaped strings, private user paths, hardware UUIDs and unexpected binaries; it cannot prove absence of every secret. No raw private evidence is copied. Ignore rules are defense in depth; use explicit file selection, not git add . or force-add audit/vendor files.

Original code/documentation retains existing copyright; public viewing, permissive reuse, model redistribution, voice/personality consent and public demo rights remain separate. No third-party grant is inferred. Q-001/Q-002 OPEN. See [current gates](release/PUBLICATION_BLOCKERS.md).
